## Prior art (compact pass, 2026-10-23, web search only; neither game was played for this pass)

- **The Stanley Parable** — narrator reacts to disobedience, polite then increasingly annoyed; critics read the game as the point that choices do not matter. Supports: answer every attempt, escalate the reaction. Sources: https://en.wikipedia.org/wiki/The_Stanley_Parable · GDC narrative review https://media.gdcvault.com/GDC2014/GameNarrativeReview/Daily_Sean_TheStanleyParable.pdf · https://www.electrondance.com/the-stanley-paradox/ · https://killscreen.com/inside-stanley-parable-game-no-one-can-describe
- **There Is No Game: Wrong Dimension** — a voice urging you to stop while the interface is the puzzle; the frustration is staged and answered. Supports: UI-as-joke (our stats screen and lockpicking tutorial), keep it short. Sources: https://www.gamedeveloper.com/game-platforms/bending-genres-and-breaking-rules-in-i-there-is-no-game-wrong-dimension-i- · https://filmstories.co.uk/features/how-i-made-there-is-no-game-wrong-dimension/ · https://www.nintendolife.com/reviews/switch-eshop/there_is_no_game_wrong_dimension
- Interpretation (agent): both comedies work because the game keeps talking back; silence after a failed action is what reads as frustration.
